# Usage

## Command line

```
mdsplit4gpt PATH_OR_FOLDER [flags]
```

### Positional argument

| Argument | Description |
|---|---|
| `PATH_OR_FOLDER` | Path to a single `.py` file or a directory tree |

### Flags

| Flag | Type | Default | Description |
|---|---|---|---|
| `--out` | path | input folder | Output folder for processed files |
| `--pyis` | path | output folder | Folder for `.pyi` stub files generated by pytype |
| `--types` | bool | `True` | Run pytype type inference |
| `--mini` | bool | `True` | Minify the Python source |
| `--mini_docs` | bool | `True` | Remove docstrings |
| `--mini_annotations` | bool | `True` | Remove type annotations |
| `--mini_asserts` | bool | `True` | Remove `assert` statements |
| `--mini_debug` | bool | `True` | Remove debug statements |
| `--mini_imports` | bool | `True` | Combine import statements |
| `--mini_obj` | bool | `True` | Remove `object` base class |
| `--mini_pass` | bool | `True` | Remove `pass` statements |
| `--mini_posargs` | bool | `True` | Convert positional args to keyword args |
| `--mini_retnone` | bool | `True` | Remove explicit `return None` |
| `--mini_shebang` | bool | `True` | Remove shebang lines |
| `--mini_globs` | bool | `False` | Rename global identifiers |
| `--mini_locs` | bool | `False` | Rename local identifiers |
| `--mini_lits` | bool | `False` | Hoist literal strings |

### Examples

```bash
# Minify a single file, no type inference
mdsplit4gpt mymodule.py --out out/ --types=False

# Process a whole project with default settings
mdsplit4gpt myproject/ --out myproject_mini/

# Aggressive minification including global/local renaming
mdsplit4gpt myproject/ --out mini/ --types=False --mini_globs=True --mini_locs=True
```

## Python API

```python
from split_python4gpt.minifier import PyTypingMinifier, PyLLMSplitter

# Minification only
m = PyTypingMinifier()
m.process_py("myproject/", out_py_folder="out/", types=False, mini=True)

# Full pipeline with token-bounded splitting
s = PyLLMSplitter(gptok_model="gpt-4", gptok_limit=8192)
s.process_py("myproject/", out_py_folder="out/", types=False, mini=True)
s.write_splits()  # writes out/split4gpt/split1.py, split2.py, …
```

## Output structure

```
out/
├── module.py          # minified copy of each source file
├── subpackage/
│   └── helper.py
└── split4gpt/
    ├── split1.py      # token-bounded chunk 1
    ├── split2.py      # token-bounded chunk 2
    └── …
```
